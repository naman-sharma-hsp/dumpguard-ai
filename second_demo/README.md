# DumpGuard AI

DumpGuard AI is an AI‑powered system that predicts illegal waste dumping hotspots in urban cities.

## Features
- Predicts dumping risk using historical data
- Visual hotspot map
- Helps cities take preventive action

## Tech Stack
- Python, Flask
- Scikit‑learn
- HTML, CSS, JavaScript
- Leaflet.js

## How to Run
1. Train model: `python model/train_model.py`
2. Start backend: `python backend/app.py`
3. Open `frontend/index.html` in browser
